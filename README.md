# 📱 Aplikasi Navigasi Compose (Kelompok 8)

Proyek ini adalah aplikasi Android yang dikembangkan untuk mendemonstrasikan implementasi **navigasi menggunakan Jetpack Compose**.  
Aplikasi ini dibuat sebagai studi kasus untuk tugas kelompok dalam mata kuliah pengembangan aplikasi mobile.

---

## 🚀 Fitur Utama

- **Navigasi Dasar:** Menunjukkan cara berpindah antar layar (*composable*) dalam aplikasi.  
- **UI Modern:** Mengimplementasikan antarmuka pengguna dengan pendekatan deklaratif dari Jetpack Compose.  
- **Struktur Proyek Terorganisir:** Menyusun file dan komponen agar mudah dikembangkan serta mendukung kolaborasi tim.  
- **Mood Tracker:** Fitur tambahan yang memungkinkan pengguna memilih suasana hati harian melalui emoji dan menerima pesan motivasi sesuai emosi yang dipilih.

---

## 🧩 Teknologi yang Digunakan

- **Kotlin** – Bahasa pemrograman utama.  
- **Jetpack Compose** – Toolkit modern dari Android untuk membangun UI deklaratif.  
- **Android Studio** – IDE yang digunakan untuk pengembangan dan pengujian aplikasi.  

---

## 👥 Pembagian Tugas Kelompok

| Nama Anggota | Tugas |

## ⚙️ Cara Pemasangan (Installation)

Ikuti langkah-langkah berikut untuk menjalankan proyek di perangkat atau emulator Android:

1. **Clone repositori ini**
   ```bash
   git clone https://github.com/Mutt150/ComposeNavigationApp_Kelompok8.git
   
2. **Buka di Android Studio**
- Buka Android Studio
- Pilih File > Open, lalu arahkan ke folder proyek yang sudah di-clone.

3. **Sinkronkan Proyek**
- Android Studio akan otomatis menyinkronkan proyek dengan Gradle.
- Pastikan kamu terhubung ke internet selama proses ini.

4. **Jalankan Aplikasi**
- Pilih perangkat fisik atau emulator Android.
- Klik tombol Run ▶️ untuk membangun dan menjalankan aplikasi.
